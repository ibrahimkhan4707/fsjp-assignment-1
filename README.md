# FSJP Assignment 1: Web Development Portfolio & React SPA

## Overview
This repository contains the source code for Assignment 1 of the Frontend Engineering course. It consists of two primary tasks demonstrating proficiency in HTML5, CSS3, Bootstrap 5, and React.js.

## Task 1: Personal Portfolio Website
A responsive personal portfolio showcasing my profile, skills, and academic projects.
* **Technologies used:** HTML5, CSS3, Bootstrap 5
* **Features:** Sticky Navbar, About Me section, Skills grid, Featured Projects, and a Contact Form. Fully responsive across mobile and desktop.

## Task 2: E-Library Single-Page Application (SPA)
A dynamic React.js application simulating a library catalog and borrowing system.
* **Technologies used:** React.js, Bootstrap 5
* **Key Concepts Implemented:** Functional Components, `useState` for state management, Props, and dynamic view toggling.
* **Features:** Users can browse the library catalog, borrow books, view their borrowed books, and return them.
